# vulkan-tutorial-ash

A rust implementation of the updated [vulkan-tutorial](https://docs.vulkan.org/tutorial/latest/00_Introduction.html) based on [ash crate](https://github.com/ash-rs/ash)

There might not be much difference with [vulkan-tutorial-rust](https://github.com/unknownue/vulkan-tutorial-rust) by [unknownue](https://github.com/unknownue), which is based on the earlier tutorial. I just wanted to follow the most recent version of the tutorial to learn the newest features and best practices.
